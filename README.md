# ALL COLLECTOR ARCHIVE

올콜렉터 빈티지 아카이브 홈페이지.

## 홈페이지 이름/문구 수정
`data/site.json` 파일만 수정하면 브라우저 제목, 좌측 브랜드명, 메인 히어로 제목과 주요 섹션 제목을 바꿀 수 있습니다.

주요 항목:
- `site_title`: 브라우저 탭 제목
- `brand_line1`, `brand_line2`: 좌측 브랜드명
- `hero_title_line1`, `hero_title_line2`: 메인 대형 제목
- `hero_description`: 메인 설명
- `archive_title`, `archive_subtitle`: 아카이브 섹션 제목
- `stories_title`, `media_title`, `contact_title`: 각 섹션 제목
- `instagram_url`: 인스타그램 링크

상품/아카이브 데이터는 기존처럼 `data/catalog.json`에서 수정합니다.
